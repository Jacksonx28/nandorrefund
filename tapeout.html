This is the whole session. The netlist below was simulated against all 32 test cases before you ever touch the canvas: 32/32 pass. Follow the rows in order, check the two simulator tests, then tape out.

[ Step 1 · Set up ]

Canvas, chain, processor.

1A

Open the canvas

Go to tapeout.net/#canvas in your own browser, the one with your wallet. Fallback if the canvas will not load: tapeout.net/old#canvas.

1B

Chain: X Layer

Make sure the chain selector says X Layer (chain 196), and connect your wallet, 0x3622…35F0. Balance needed: about 0.023 OKB. You hold about 0.0438.

1C

Processor: HashPortAI

Pick HashPortAI (#167) from the processor dropdown, the same processor as circuit #50. Do not create a new processor.

[ Step 2 · Wire the gates ]

Five inputs in, three verdicts out.

Name the input pins in this order: IN0 = D (delivered), IN1 = H (hash match), IN2 = C (checklist ok), IN3 = T (deadline met), IN4 = A (client accepted). Name the outputs: OUT0 = RELEASE, OUT1 = REFUND, OUT2 = SPLIT50. Then place NAND gates and connect them exactly as the table says. A gate wired to the same node twice, like G2 (n1, n1), is just a NOT.

[ Step 3 · Check before you pay ]

Four simulator tests. All must pass.

Run these in the canvas simulator before taping out. If any fails, stop and message Shadow with the gate you are on. Do not tape out a circuit that fails these.

TEST A

All facts good, late but accepted

Set D=1, H=1, C=1, T=0, A=1. Expected: RELEASE (OUT0) = 1 and OUT1, OUT2 = 0.

TEST B

Nothing delivered

Set D=0, H=0, C=0, T=0, A=0. Expected: REFUND (OUT1) = 1 and OUT0, OUT2 = 0.

TEST C

Delivered, matching, never accepted

Set D=1, H=1, C=1, T=1, A=0. Expected: SPLIT50 (OUT2) = 1 and OUT0, OUT1 = 0.

TEST D

Wrong file delivered

Set D=1, H=0, C=1, T=1, A=1. Expected: REFUND (OUT1) = 1 and OUT0, OUT2 = 0.

[ Step 4 · Tape out ]

One signature. Then hand it to Shadow.

Click tape-out and sign the transaction in your wallet, about 0.023 OKB in total. Send Shadow the new circuit ID (or the transaction link) in chat. Shadow then verifies all 32 vectors read-only, builds the escrow deploy tool with the real circuit ID inside, and posts that link for step 5, the deploy and the test job.
